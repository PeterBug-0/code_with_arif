## Rules

1. Never push directly to main.
2. Create a branch for every assignment.
3. Commit meaningful changes.
4. Push the branch.
5. Open a Pull Request.
6. Address review comments.
7. Mentor merges the PR after approval.

## Assignment Complete When:

- ✓ Program runs
- ✓ Required functionality works
- ✓ Code is readable
- ✓ No unnecessary console logs
- ✓ README explains how to run it
- ✓ Meaningful commits exist
- ✓ Pull Request opened
- ✓ Review comments resolved
- ✓ PR merged into main
